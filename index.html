WebAR SCENE GENERATOR

カメラでその場を撮影すると、AIがシーンを認識し、状況に合った3Dオブジェクトをその場に自動生成して配置します。重力で落下・積み重ねが反映され、Pixel 7a 等の対応端末では WebXR Depth API による GPU オクルージョンで実物の陰に自然に隠れます。

※ WebXR Hit-Test 対応の Android Chrome 最新版推奨(Pixel 7a 等)。iOS Safari は非対応です。
※ GPU Depth Occlusion(WebXR Depth API)は ARCore 対応端末(Pixel 7a/7/8 等)のみ有効。非対応機種では物理(重力・積み重ね)のみ動作します。
※ 画像認識はすべて端末内(ブラウザ)で実行されます。APIキーや通信は不要です。

このブラウザはWebXR(AR)に対応していません。
Android の Chrome 最新版でお試しください。

(HTTPS環境が必要です。file://では動作しません)
